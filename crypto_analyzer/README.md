# CryptoAnalyzer - консольный анализатор криптовалют на Python

## Идея проекта
Пользователь выбирает криптовалюту, программа получает данные о цене и объёмах за последние 7 дней через CoinGecko API, затем отправляет эти данные в Mistral AI и получает анализ с прогнозом на русском языке

В проекте есть регистрация, авторизация и сохранение истории запросов в базу данных через SQLAlchemy

## Что используется
- Python
- requests
- SQLAlchemy
- python-dotenv
- mistralai (через HTTP-запросы)
- PostgreSQL для финальной версии

## Файлы проекта
- "main.py" — главное меню программы, регистрация, вход, анализ
- "models.py" — модели базы данных (User, AnalysisHistory)
- "services.py" — работа с CoinGecko API и Mistral AI
- "requirements.txt" — список библиотек
- ".env.example" — пример настроек

## Как запустить
1. Установить библиотеки:
python3 -m pip install -r requirements.txt
2. Создать файл ".env":
cp .env.example .env
3. В файле ".env" указать ключ Mistral:
MISTRAL_API_KEY=ваш_ключ_mistral
4.  Запустить main.py

## Как пользоваться
После запуска появится главное меню:

- Регистрация
- Вход
- Выход

Сначала нужно зарегистрироваться, затем войти в аккаунт.

После входа доступны действия:
- выбрать криптовалюту (bitcoin, ethereum, binancecoin, cardano, solana)
- ввести дополнительный вопрос или оставить пустым
- получить анализ от Mistral AI
- посмотреть историю предыдущих анализов
- выйти из аккаунта

Пример: выбираете "1" для Bitcoin, не вводите дополнительный вопрос — получаете прогноз по данным за 7 дней.

## База данных
База данных и таблицы создаются автоматически при первом запуске через models.py (функция init_db). Для быстрой проверки используется SQLite, настройки базы не нужно указывать отдельно.

## Если API не работает
CoinGecko и Mistral — внешние сервисы. При отсутствии интернета или недоступности сервисов программа не завершается с ошибкой, а выводит понятное сообщение пользователю.
